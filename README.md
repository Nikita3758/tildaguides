# tildaguides

Учебный веб-проект, содержащий материалы и руководство по разработке на платформе Tilda.

## Структура проекта

* `css/` — стили проекта
* `js/` — скрипты и интерактивные элементы
* `images/` — графические ресурсы и изображения
* `pages/` — дополнительные страницы проекта
* `index.html` — главная страница
